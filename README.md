# Yintjingga Visitor Safety

Online preview of a student prototype for the EWB Challenge (Design Area 2, Opportunity 2.4): visitor check-in and a ranger console that flags overdue parties automatically.

Live page: https://peterhanhhh-cyber.github.io/yintjingga-visitor-safety/

Check-ins are stored in the viewer's own browser only. Content is illustrative and must be approved by the Yintjingga Aboriginal Corporation before use.
